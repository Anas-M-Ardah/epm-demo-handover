# Troubleshooting the demonstration

| Symptom | Check and recovery |
| --- | --- |
| Role cannot find a new workspace | Reuse supported workspace code ub; labels alone do not grant scope. Ask the owner to assign access rather than using the super role for the full story. |
| Duplicate contract or letter | A previous run exists. Choose and record a consistent new suffix; never edit someone else's record. |
| Workbook total differs | Confirm correct first sheet, six column mappings, native currency and no totals row. Do not approve a mismatched file. |
| Schedule rejects a dependency | Confirm matching supplied file and unchanged activity IDs. Do not delete links merely to obtain approval. |
| No approval action | Check current role, submitter, record state and deployment version. |
| Period cannot close | Resolve the named pending readings, missing evidence or actual-date issue from the close panel. Never bypass by deleting history. |
| File row exists but viewer fails | Upload the bytes using the registered filename. Metadata is not file content. PDF/image inline viewing differs from XER/XLSX download. |
| No overdue SLA | Match data date D and letter D minus 16; leave its first desk unreleased; enable the rule; allow evaluation to run. |
| SLA no longer says 16 days | You advanced the project date. Use the actual elapsed number or repeat in a fresh project; do not misstate the screen. |
| Supply quantity rejected | Check allocated quantity, available warehouse quantity, previous preliminary/final totals and beneficiary role. Reinspection cannot receive stock again. |
| Supplier correction still blocks final | Correction needs an independent beneficiary reinspection with conforming result. |
| Zero-value change stuck at pricing | Confirm deployment includes the explicit zero-impact approval fix. Do not invent a price or bypass stages. |
| Spending exceeds budget | Confirm finance values and certificate components; this kit's cumulative 350 million is below the 4.1-billion revised budget and 2.2-billion allocation. |
| Portfolio has fewer projects than expected | Check workspace filter and role scope; optional extension projects are manually entered, not automatically seeded. |
| A label/action differs materially | Stop that step, record screenshot/build/role, and have the application owner reconcile the deployed version with this guide. |

No script in this repository resets or seeds a database. Do not use development reset endpoints to solve a demonstration mismatch.
